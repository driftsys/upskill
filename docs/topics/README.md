# Concern reference

Read these topics in order for an overview, or start with the concern you need.
The content format is a standalone Draft contract. Topics 0005 to 0008 describe
library code that was removed from `main` by
[AD-0042](../adr/0042-resteer-customization-delivery.md) and are marked
withdrawn. Topics 0002 to 0004 and 0009 mark their withdrawn sections
individually. Only the sections that are not marked withdrawn describe
implemented architecture. Status and activation limits apply to individual
sections; this consolidation approves no new behavior. ADRs retain decision
rationale and their independent identifiers.

history. Old specification and design paths remain compatibility entrypoints.
