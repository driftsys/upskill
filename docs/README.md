# Documentation map

| Location                                  | Purpose and authority                                             |
| ----------------------------------------- | ----------------------------------------------------------------- |
| [Book](book/SUMMARY.md)                   | Published user guidance for implemented behavior.                 |
| [Specifications](specification/README.md) | Tool and content contracts; each document retains its own status. |
| [ADRs](adr/README.md)                     | Decisions and rationale; only Accepted decisions are binding.     |
| [Design](design/README.md)                | Architecture as implemented, checked against code and tests.      |
| [Technotes](technotes/README.md)          | Informative investigations and dated external evidence.           |
| [WIP](wip/README.md)                      | Active or unreconciled designs and plans.                         |
| [Archive](archive/README.md)              | Completed or superseded working documents and provenance.         |

The book includes canonical specification sources rather than maintaining a
second copy. Research, working documents and archive assets are outside its
publication root. Existing published chapter filenames remain unchanged.

See [Contributing](../CONTRIBUTING.md#documentation-lifecycle) for document
transitions and verification. Moving a document does not approve its contents,
change an ADR's status, or establish that a feature has shipped.

Current planning: [Upskill roadmap](roadmap.md), with the four-client MVP first,
post-MVP cleanup, and additional customization management afterward. Planned
scope remains separate from implemented contracts in the book and
specifications.
