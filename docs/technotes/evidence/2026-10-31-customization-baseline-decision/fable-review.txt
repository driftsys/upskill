**Reviewer:** claude-fable-5-1 (Claude CLI). Evidence-only; no tools used, no files changed.

**Verdict: YES WITH REQUIRED CORRECTIONS**

**Rationale.** AD-0041 separates the design choice (A's organization: one source, copied outputs, one effective representation per item/client, explicit sharing exceptions) from installed paths, packaging, native qualification and production activation, and it keeps AD-0040/Topic 0009, step‑7 adoption, Q10/Q11, CD‑01–11, preservation classes, the one-copy Claude/Copilot rule exception and the four-client release scope in force. It correctly states that Q11/Q11b are unchanged, that a directory name does not isolate readers, that equal bytes do not prove consumption, and that the overlay has only offline guards. Nothing in it changes schema‑1 behaviour or admits any native route. A can therefore be adopted now as an organizing baseline without inferring any native result.

**Material required corrections.**
1. Define "default" under A. "A client-specific body replaces its default" must state that the default is itself a generated per-item representation, not a B-style shared installed catalog, and that A does not require a default representation to exist for every item/client.
2. The removal→unavailability policy and "no symlinks" are additional commitments bundled with A. Either declare them explicitly as adopted design direction (and align the brief's item 5, which lists it as behaviour to approve, with the ADR's "proposed future lifecycle policy" wording) or split them. Keep the explicit "not a change to schema‑1 remove" clause.
3. "A qualified hook/adapter is used where needed" must not pre-authorize hooks/adapters as new delivery kinds; general hooks remain a pending decision per the ADR's own boundaries.
4. Record in the ADR (not only the brief) that the Q11b profile shows a Claude project-marketplace registration exposes Claude-only content to Copilot, and that Q11b's separate native-preservation failure blocks that route's lifecycle claims under A as well; A does not reclassify it.
5. State that owned-subagents, OpenCode package skill sources and Codex trust remain pending decisions that A's selection rules do not pre-empt (currently implied, make explicit).

**What remains blocked.** Every unqualified native route: Q11 Copilot→Claude direction; Q11b project-registration exposure and native preservation; Copilot per-plugin `enabledPlugins=false` overlay (no native sequence executed; no masked/unmasked/remasked result may be inferred); OpenCode downstream (Q5 positive failed); Codex recorded-history duplication; installed `.agents/<client>` paths, package granularity, defaults, override syntax, lock schema; new Q11 gate, preservation waiver, schema‑2 activation, reduced release scope; owned implementation before step‑7 adoption and the applicable evidence gates. Native probe spending remains a separate conditional step.

**Overturning condition.** A bounded, version/scope/OS-pinned native experiment in which, for a required kind, no qualified exclusion exists that keeps an unintended compatibility reader from consuming a client-specific representation (e.g., overlay masking fails in Copilot's project scope and no other selector is available), while a single shared default body under B satisfies the reader contract, duplicate prevention and clean removal with preserved capabilities and fewer effects. That would trigger the ADR's own reconsideration clause and overturn A as baseline; a mere route failure would not.
